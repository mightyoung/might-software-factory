# Might Software Factory

前后端分离的 B/S 软件工厂基础框架：让 AI 与开发者在统一公共能力、数据模型和发布规范内构建业务系统。

## 当前状态

**设计文档初始化，尚未实现或部署。** 当前公共服务方案为 v1.1（2026-10-29）。本仓库未提供运行中的服务、应用构建、测试结果或性能验证；后续开发应先通过兼容和隔离门禁。

## 设计方向

- 公共能力、业务、展示三层；纵向语义与能力登记服务页面和受限 Agent。
- Java / Spring 模块化单体，PostgreSQL 完整功能档，jOOQ，嵌入式 Flowable。
- 首期数据库持久会话、私有本地文件、站内通知和持久任务；不强制 Redis、MQ、Keycloak 或对象存储集群。
- 第一版台账由 AI/开发者代码配置，审查、测试后发布；不做管理员在线加字段即时生效。
- 首期仅电脑浏览器；最小登录加载，其他应用/表单/字典按需获取。
- 后端最终鉴权覆盖所有入口，Agent 不直连数据库。

## 版本与实施边界

Spring Boot 4.1.2、Modulith 2.1.1、Flowable 8.0.0 是设计基线，**组合尚未构建验证**；Flowable 发布依赖基于 Boot 4.0.2，需先做集成测试。具体依赖锁和 SBOM 待实施形成。
