# Might 3D Engine · Phase 1a

独立 Three.js/TypeScript 程序化设备预览。运行 `npm ci && npm test && npm run build && npm run check:bundle`；使用 `npm run dev` 打开沙盒。主工作台和 Office 不引用它，本切片没有生产菜单入口或后端权限、数据、发布实现。

选择列表中的设备可将三维相机移到对应稳定 ID；不支持 WebGL 2 时仍能查看和选择同一份场景数据。渲染只在相机、设备状态、视口尺寸或恢复时触发。渲染器、事件、调度器、几何体和材质属于每个挂载实例；不共享租户或浏览器持久状态。二维列表是原型保底，不等于完整二维地图。

后续补 GLB 资产校验、引用计数、LOD/解码、模型管理、预制体及大屏双态。当前未验证 50 次模型切换实机显存趋势、长期投屏性能或生产可用性。280 KiB 是独立预览资产硬门槛，和主工作台预算无关。


Starter v1 首批加入传送带、廊道、机械臂和螺旋传送机。预览可切换传送带的 4 / 8 米尺寸，实际重建结构和共享资源；端口是设备的局部坐标（米），还不是业务或物联绑定。初代盒体/圆柱和文档仍可读。

节拍仿真目前为独立、纯 TypeScript 串行线内核，详见 [sim 说明](sim/README.md)。它纳入类型检查和回归，未接入浏览器预览或 Worker，不会增加运行态包体积。

本地模型预览支持自包含 GLB 2.0 的无纹理静态网格（单文件最多 8 MiB、4 个互不复用的网格、总计 10 万顶点及 15 万面），显示从顶点实际计算的米制包围盒。文件只在浏览器本地内存处理，不外传或入库；支持校验失败保留前一模型以及返回合成场景。测试覆盖 50 次本地模型切换和释放，不视为实机显存长期稳定认证。当前读取最多 16 个无环节点的变换、法线、有效步长和简单不透明材质声明；每个网格仅支持一个三角面图元，合并后按实际变换后的顶点计算包围盒，预览仍使用统一材质。不支持贴图、外链、动画或压缩扩展。

交互工具 v3：四类参数化设备均可按 0.5 米调整高度（+Y，保持底面）。仅传送带和廊道支持水平四面调整（保持对侧）；机械臂和螺旋传送机的外形不贴合标称长宽边界。GLB 提供显式米/毫米报告；异常大坐标只提醒核对，不按阈值自动转换。

顶视平面草稿支持鼠标/触屏点选及 X/Z 数值键盘录入、连续墙段、0.1/0.5/1 米网格、正交锁定与闭合区域的平方米数。拒绝重复墙段、零长线及自交区域，保留失败草稿。此类几何在页面内存中，无业务发布或复合楼层能力。

选中参数化设备后也可拖动视口金色面手柄，支持的面与键盘面板一致。沿局部面外法线投影计算变化，抬手才提交，Esc、失焦、视口变化或设备重建均取消拖动，不写入拖动结果；键盘面板仍保留。视角过平时隐藏该方向的手柄，避免几像素移动触发不可控尺寸跳变。

顶视图完成墙段后会同步生成三维墙体预览（3 米高、0.2 米厚）；替换几何时释放上一组。查看独立 GLB 时暂时隐藏场景墙体，返回合成场景后恢复。区域仍为二维草稿，未写入正式场景文档。

会话模型库允许把已验证 GLB 显式保留在当前页面内存，按 SHA-256 去重，最多 8 件/32 MiB；可重新预览和移除。无私有对象存储、刷新后保留、跨租户、正式资产引用或后台上传。
