# 确定性节拍仿真：单条串行线

`runDiscreteEventSimulation` 仅接受 1–64 个串行工位和 1–10,000 件整批物料；毫秒级时间，先进先出，不使用 DOM、网络、随机数或生产数据。整批在 0 时刻可投入；工位单件加工，转运时间计入该工位占用时间。缓冲位是下游工位之前的**等待位**，不含正在加工的物料；零等待位时须直接交给下游工位。下游满时，工位保留已经完成加工及转运的单位，直至可交接；此等待单独计入上游堵料时间，不充当加工时间。首站没有上游，因此其等待位数量不起作用。

理论每小时产能是 3600 除以最大工位服务时长，实际批次估算是批量除以该批次耗时，包含从空线启动和最后一件出线。利用率不包含堵料。多工位并列最大服务时长时，指标展示首个同节拍工位。不能作为现有生产产能的实测值。

拒绝环、分支、合流、断开的节点及找不到的引用。不支持损耗返工、并行设备、间歇投料、异步物流运输或人员/工位交互。无浏览器依赖，能从 Web Worker 入口导入，但目前未接产品界面或 Worker 消息协议。

验证：`node --experimental-strip-types --test sim/*.test.ts`。
