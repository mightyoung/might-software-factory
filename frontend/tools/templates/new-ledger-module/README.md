# 新业务台账接入模板

普通台账不复制一个前端页面。配置通过后端登记或发布，现有
`EntityLedgerPage` 按定义生成列表、分页、筛选、详情和表单，
复用租户路由、OpenAPI 契约与现有选择/键盘语义。

1. 在后端登记应用和实体，发布定义及读写权限；准确对齐 `entity-ledger` 契约。
2. 用 `registered-ledger.ts` 填入 **合成测试**所需的应用、菜单和链接示例。HTTP
   场景的应用与菜单来自会话和菜单 API，不使用这个工具模拟角色或授权。
3. 走 `/t/<tenant>/apps/<app>/entities/<entity>`，验证正确租户的列表、详情和表单，
   验证其它租户及无权用户被拒绝，再覆盖引用项、空列表和提交错误。
4. 只有通用定义无法表达的流程，才考虑单独的业务页面；先确认保留契约和预算。

模板代码由 `src/features/ledger/registeredLedgerTemplate.test.ts` 实际导入；
类型检查与单测会发现它与仓库接口的漂移。不会打进生产工作台。
