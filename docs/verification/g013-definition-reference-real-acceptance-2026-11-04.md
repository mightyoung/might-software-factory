# G013 定义、引用与导航实库验收 — 2026-11-04

本批接续 PR #44，完成真实 PostgreSQL／TLS HTTPS 的限定验收，并修复 CREATE-only 导航和授权后通配条件请求。44 项实库套件全部通过；默认与兼容配置的完整后端验证分别通过 878 项和 939 项。本结论仅覆盖下述路径，不代表完整 G013 或 P0–P2 完成。

## 行为与覆盖范围

- 导航分别判断 Finding READ 与 CREATE：仅有 CREATE 的成员可取得上报入口和菜单，仅有 READ 的成员不获得创建能力；两者都没有时不发布应用入口。应用有效性和当前身份检查仍先执行。
- 定义接口先解析当前身份、应用授权与 READ／CREATE 投影，再处理条件请求。先保留 Spring 的条件判断结果，仅对单个完整、去除首尾空白后等于 `*` 的 `If-None-Match` 补充无响应体 `304`；GET／HEAD 保留 ETag、`private, no-cache` 和 `Vary: Cookie`。普通弱标签、强标签列表及异常／混合／重复标签仍走原框架判断，没有新增通用 If-Match 或日期语义。
- 实库套件使用真实持久身份登录，覆盖 CREATE-only／READ-only／无权限导航、定义投影、凭据与账号／主体／成员／租户／应用授权变化，以及撤权先于条件响应。
- 引用查询覆盖实际 UTF-8／媒体类型／字节与码点限制、严格 JSON、字面搜索、UUID keyset 分页、租户与活动状态／组织范围过滤和 FORCE RLS。
- 连接观察器记录真实 PostgreSQL PID、事务时刻、租户和只读 RR 边界；确定性写入屏障验证同一在途快照不会混合新候选状态，后续请求会拒绝已撤销的授权。观察器有单独的 6 项契约测试，本报告不将其计作实库用例。

44 项套件包含一个进程内权限对象生命周期测试及连接观察／快照探针，不能描述成 44 个独立 HTTP 业务命令。其余接口与登录路径通过本地 TLS HTTPS 调用真实后端；没有真实浏览器操作。
