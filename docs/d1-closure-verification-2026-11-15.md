本机任务专属 Docker PostgreSQL 18、Linux ARM64 JDK 21 和独立 `msf_d0_d1_*_test` 数据库；migrator/runtime 分离、非特权、不继承角色。D1 权限档继承原 D0 精确权限断言并只增加五张新表和一个控制表列，未改变 D0 旧档语义。

真实浏览器连接编译页面、HTTPS 后端和 runtime 数据源，覆盖新建后刷新、编辑后刷新、两标签版本冲突、仅创建用户、普通读者和组织范围。未知结果用真实服务器先提交再丢弃响应模拟传输故障，随后原键重试；不替换后端成功响应。跨租户、当前撤权、锁竞争、回滚、RLS 和精确权限以真实 PostgreSQL 测试证明。

首轮完整实库回归因源码快照未初始化 Git 元数据，被旧文件存储保护拒绝。该次失败日志保留，修正私有快照环境后重跑；没有削弱保护、改产品代码或计入通过数。
