# Might 数字孪生 starter v1：并行集成

保留 #108 已验证的 Three.js、Zod 精确版本、独立构建、2D 保底和 WebGL 恢复；不覆盖整个目录。最新工程包作为设计输入，不运行其中脚本或后台迁移。

1. 参数化设备：沿用 ISA-95 类别命名，首批传送带、廊道、机械臂和螺旋传送机；增量接受尺寸、姿态以及稳定 ID，在现有模型预览实际渲染。重新生成结构件而非拉伸整件；定义长度 X / 宽度 Z / 高度 Y（米）、设备底面和局部端口。显式限制模型规模并验证共享几何体、材质只释放一次。其余设备类别和完整六级树另行接入。
2. 节拍仿真：独立纯 TypeScript，先验证单入口线性流程、真实有限队列与阻塞、守恒及仿真产能；不能复用附件中单分支循环、队列超限仍入队、阻塞次数充当秒的实现。Web Worker 和 UI 接入另验。
3. 视频/物联/后台：预览不读真源。视频资源管理先验证 4 路硬上限、实际释放、离视口定时与权限撤回，不能把 LRU 小窗口记录当作断流。暂不应用 SQL 或启动容器：附件的单列外键无法保证父节点、模型及点位属于同租户，需对齐项目已有空间、设备、权限和 Flyway 规则；容器使用浮动标签和全接口端口，不是可直接部署配置。GLB 体检、完整模型管理、预制体、Studio/Player 及生产联动继续独立推进。
