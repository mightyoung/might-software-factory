# 三维 Studio v3：顶视平面绘图

补齐 v3 附件缺失的底层几何能力，而不依赖未提供的 Studio v2。此次切片放在独立预览：SVG 正交顶视图，沿 X/Z 米制平面画连续墙段和闭合功能区，支持 0.1/0.5/1 米网格、Shift 或勾选正交约束，显示草稿与闭合区域面积。键盘数值输入和指针使用同一逻辑。

内部按十分之一米整数坐标计算，避免面积或线段相交的浮点误判。拒绝零长墙段、重复墙、自交或退化区域；无效闭合保留草稿供取消重画。仅保存在页面内存，不输出正式测绘图，不写入已发布场景，不做三维墙体、挖洞或楼层联动。需通过算法测试、实际 Chrome 的指针/键盘和移动尺寸验证及既有预览预算。
