# 三维 Studio 工具集 v3 集成

依据用户追加的交互工具包，在 #110 已验证的组件上适配，而不是覆盖。首批以参数化设备面缩放和 GLB 单位确认交付，分别覆盖纯数学测试和实际浏览器交互。平面工具包引用未随附的 `FloorplanBuilder`；先在现有场景契约设计墙线/区多边形，再独立实现吸附、正交约束、面积和非法多边形拒绝，不能称现有包可直接接通。

- 缩放按设备局部五面：±X 为长、±Z 为宽、+Y 为高，底面不动；水平中心位移基于**夹紧后的变化**和设备绕 Y 轴旋转换算。第一批以键盘可达按钮控制，不冒称已支持视口鼠标拖拽。
- GLB 校验仍严格拒绝纹理和外链，已有底面中心对齐；只增加显式 m/mm 读取，超过 500 只提醒核对，不根据阈值自动重解释。大数可能是以米表达的真实大尺度资产。尺寸报告与仅影响取景的预览归一化不能混用。
- 不新增依赖、联网、生产或后台存储。发布前按实际 dev 及依赖重验。Stage 3 附件声明的 Studio v2 在本轮未找到同名文件，不阻塞上述独立能力。
