# D1 有界整理计划

作者：主执行代理。审阅：独立 architect；执行：独立 executor。范围是相对 D0 提交 `c95455a` 的本轮 D1 变更文件，包含实现、测试、协议与工具；不触及冻结 D0、原始脏工作区或其它模块的未修改文件。

## 行为锁

- 固定源码快照的 Linux JDK 21 离线回归：2562 项，失败、错误、跳过均为 0。
- 原 25 个实库测试类加 `ToolLedgerPostgresIT`、运行账号权限守卫和完整前端回归是整理前后的回归出口。
- 真实 HTTPS 浏览器已覆盖新建/编辑后刷新、旧版本冲突、提交成功但响应丢失后的原键重放、仅创建权限及组织范围。跨租户由真实实库测试和前端路由测试覆盖。
- V28 真实 Flyway 缺失、兼容、冲突三态升级已通过。整理不得改变迁移历史和权限语义。

## 回退路径清单与约束

| 位置 | 分类与依据 | 处理 |
| --- | --- | --- |
| `LedgerRuntime` 的可选动作预览捕获 AccessDenied | 有依据的展示降级；必须动作仍拒绝，读者无需写权限 | 保留，并检查不会吞掉数据库/身份故障 |
| HTTP/字段解析器将无效格式映射为输入错误 | 有依据的边界拒绝；重复键、超限、类型错误已有测试 | 保留显式拒绝；不加成功默认值 |
| `EntityLedgerForm` 的未知提交原样重试 | 有依据的故障恢复；保存原键、规范化载荷和版本，服务端重新授权 | 保留；禁止生成新键或合成成功 |
| 引用候选失败与过期会话处理 | 有依据的失败关闭；显示失败并阻止未验证选择，旧组件结果被忽略 | 保留；不得读取本地模拟候选补齐 |
| 既有 finding 权限别名兼容 | 有依据的旧接口兼容；新台账使用 canonical permission 集合 | 保留已有契约与测试 |

若发现掩盖失败的回退、跨层改造或协议变更，先向主执行代理报告，不在整理中顺手扩张设计。

## 顺序与停止条件

1. 检查死代码、未使用导入/参数、调试残留；只删除可证明无行为作用的内容。
2. 检查重复逻辑与转发包装；只有直接复用且不改变边界时才简化，不为减少行数新增抽象。
3. 检查命名、错误处理和通用页面信息；保留原键恢复、可访问性及权限提示。
4. 检查必要回归覆盖；已有覆盖足够时不增加镜像实现的测试。

无可证明收益时允许零代码变更，并记录原因。不得添加依赖、扩大范围或修改已应用迁移。整理后重跑后端离线和实库、前端单测/类型检查/构建/包预算/生成协议/mock E2E，并用最终产物复核真实浏览器。仓库未配置独立 lint 命令时如实记录，不能将其写成已通过。

保留边界：D1 不含 D2 借还流程、D3 第二台账复用成本证明、D8 下游事件投递；Spring 事务超时配置不作为数据库锁等待硬上限的证明。引用详情目前可显示 UUID，不能通过额外读取 CREATE 候选来扩张普通读者权限。
