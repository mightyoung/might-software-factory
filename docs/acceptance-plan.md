# 公共服务验收计划

**状态：全部未执行。** 本文件仅列未来开发门禁，不代表存在代码、通过测试或上线能力。对应[设计 v1.1](public-services-design.md)。

## P0 兼容
- [ ] 固定JDK发行版、依赖锁、SBOM及许可证清单。
- [ ] Boot/Modulith/Flowable组合启动、新库建表、旧库升级。
- [ ] 主业务、审批引擎、审计和持久事件事务统一回滚。
- [ ] Session、CSRF、流程计时器及任务重启恢复。

## 隔离与安全
- [ ] 恶意tenant、跨租户对象/任务/文件ID、count/export/autocomplete不泄漏。
- [ ] 多标签页不串租户；连接池归还后无上下文残留；RLS运行身份不得绕过。
- [ ] 成员离职只撤本租户；个人/部门/岗位多来源授权正确撤销。
- [ ] Agent委托、scope、确认要求、撤权和审计与人类入口一致。
- [ ] 伪MIME/路径穿越/主动内容/扫描失败安全阻断；下载复核业务权限。

## 一致性与恢复
- [ ] 主记录和从属明细原子保存，独立关联实体不误级联删除。
- [ ] 历史快照按声明冻结，列表/表单/详情字段版本一致。
- [ ] 重复保存、并发审批、同键异参均有确定结果。
- [ ] 无审批人不自动通过；转派/离职/版本迁移可审计。
- [ ] 各故障点杀进程，任务可恢复，外部UNKNOWN不冒称成功或盲目重发。
- [ ] 从备份恢复业务、流程、附件一致，恢复环境禁发外部副作用。

## 电脑浏览器与性能
- [ ] 首期仅桌面浏览器；键盘/鼠标可达，移动端不是本期门禁。
- [ ] 登录仅加载身份、当前应用菜单、必要权限和轻量应用列表。
- [ ] 其他应用/表单/字典按需；组织/用户/引用远程分页；大明细按需。
- [ ] 缓存含租户/应用/版本，撤权不等缓存自然过期；服务端继续最终鉴权。
- [ ] 批量/导出等长任务异步；SQL、AST、返回量、提交大小和截止时间有界。
- [ ] 冷/热缓存、大组织、多应用、复杂表单、慢网络及断线重试测量。
- [ ] 报告实际硬件、并发、数据量、P50/P95/P99、错误/超时率、SQL及前端长任务。

建议预算：登录成功至可操作首屏P95≤2秒，普通分页查询P95≤1秒，常规聚合保存P95≤2秒。**仅待测工程目标，非已达结果、非SLA。** 测试恢复目标RPO≤24h/RTO≤4h同样待演练。超标先定位SQL/网络/配置/渲染，不以切换Java/Rust代替诊断。

## 结果记录规则
每次执行补充commit、环境、时间、数据集规模、命令/测试方法、完整结果和失败原因。保持失败与未知，不把已派发或已规划记为通过。
