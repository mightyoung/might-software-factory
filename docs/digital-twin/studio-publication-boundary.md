# Studio 发布到 Player：服务端接入边界（未接线）

本提交只有纯 Java 的发布决策与几何指标。放在现有 `platformadmin.digitaltwin` 内部包，不新增 Spring 扫描模块、端点、权限种子、数据库表或部署项。`Caller` 和 `DraftFacts` 只是未来服务适配器的输入，不能来自客户端声明，不证明已有服务端鉴权或完整 Studio JSON 验证。

## 应接入的现有边界

1. HTTP 层不用客户端租户字段或角色，通过 `SessionContextResolver.currentTenant()` 获取经过验证的 `CurrentTenantContext`（UUID 租户、成员与权限 epoch）。参考 `LedgerConfigurationService` 在 `IdentitySecurityTransaction` 中同时检查应用启用、`EffectivePermissions` 和租户资源查询；本业务权限分别映射 `studio:publish` 和 `player:read`，不采用「发布隐含读取」。权限尚未注册，命名与应用资源目录后续单独评审。用户未授权时先拒绝，不能泄露目标存在或版本。
2. API 层使用受控指令（目标场景标识＋明确预期发布版本＋有界草稿）和只读查询（目标场景标识＋可选正整数版本），不传任意租户主键、资产 URL、权限列表或任何客户端计算指标。先按 Studio v1 256 KiB 负载和严格字段校验准备**同一规范化字节串**，从同一解析结果提取设备/墙/区事实和 SHA-256，再调用域决策。调用方不得自行拼装 `DraftFacts` 以绕过完整解析。版本为 0 表示尚未发布；过期指令返回冲突，即便内容恰相同；当前版本及内容一致返回已有版本，不写新记录。墙长与区域面积由服务算出，面积是各区相加，不是重叠面合并面积。
3. Repository 用当前租户 UUID＋场景 key 选中一个发布流，先锁和复读当前头，再比较预期版本。新增不可变快照与审计必须同事务，唯一键 `(tenant_id, screen_key, version)` 保底，指针只能引用同一租户的有效历史版。禁止把无条件 UPSERT 写入快照；防止并发首发产生两条 v1、旧授权快照重放、回滚后头提前推进。若后续引入已登记资产，所有引用必须以租户限定、校验同一元数据/状态并使用 files 已有生命周期和私有对象授权，不以 URL 或摘要代替拥有权。
4. 附件草案的 `twin_screen_doc.published_doc` 只能存一个当前值，不能当历史账；附件使用的 `VARCHAR(64)` 租户和多处只按 UUID 的外键不能直接替代仓库既有 UUID 租户与组合外键约束。不要原样执行 starter SQL（含 ltree、可选 TimescaleDB 和 IoT/视频表）；暂不建第二套 tenant、存储、授权、审计或设备目录。此阶段不涉及 UNS、视频、数据库扩展或真实数据。
5. Player 路由有读权限才可按租户及版本取**已发布**快照，不返回草稿、凭据、其他租户存在与否，也不自动升级固定版本。发布前需在契约和生成器中锁定响应错误与验证，包括无会话 401、不具备权限 403、授权租户内版本不存在 404、陈旧版本 409，以及 schema 或坐标不合法；未授权与跨租户测试应显式核对不泄露数据。

## 尚需生产集成验证

两租户同 screen key 的数据隔离；读和发布授予/撤回的独立性；关闭应用失败；并发首次发版/相同头更新各只允许一个新增；在认证事务中撤权和失败回滚；旧版本保持不变、Player 永远不见草稿；服务端对未识别字段、非法 URL/外链、几何和体积硬门限；同一规范化字节串的哈希及指标一致；真实 PostgreSQL 事务与浏览器无真实数据的端到端。以上均不是当前已执行的验证。

## 当前离线解码增量

`StudioDraftDecoder` 接受 Studio v1 场景标识、方块/圆柱设备、四类已登记的参数化设备、
墙体、区域、基于本场景设备的命名巡视机位，以及已定义的 HUD 项。
设备、几何、线路与 HUD 数组顺序保留。字段顺序、格式空白、数值表示及标签首尾空白统一；
参数化设备未提供旋转时按前端契约规范为零。服务端按规范化 UTF-8 字节计算 SHA-256，
同时提供相同载荷的几何与设备事实。返回字节副本不会改变内部结果；
墙/区复用已有发布策略校验。

坐标/尺寸小数最多保留 24 位，严格整数坐标要求 JSON 整数。
选填数组的显式空值与省略保持区分，JSON null 拒绝。外链、纹理、资产引用和未知扩展
即使为空也拒绝，不静默删除。这是发布候选子集的规范化，不是通用 JSON 规范化。
测试资源取自合成前端工作台场景（私有组合提交 223f453 的 `runtime/main.ts`），
另添加已支持的巡视和 HUD 样例。解码器尚未接 HTTP、持久化或 Player，也不证明真实租户权限。

并在访问存储前核对草稿与目标屏对应。存储端口必须锁定并读取同一目标；首次发布没有头

不会再次写入。旧版本即使内容相同仍冲突。事务适配器必须在快照与审计均提交后才返回；

事务内授权；本增量没有注册权限、端点或数据库。
